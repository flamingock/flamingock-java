- Creating the collection flamingockEvents(following the pattern and practices we have followed for the other collections for the audit store), with the right indexes







- craete a method in the audit store to retrieve the last event for a streamId.



- create a method in the audit store to retrieve all the non-acknowledged events(with a limit passed as parameter)



- create a method in the audit store to acknowledge all the events, which id´s are pased as parameter.
